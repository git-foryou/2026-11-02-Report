## 문제 2.
	(1) 두 정수의 값을 서로 바꾸는 swap 함수를 포인터를 활용하여 완성하시오.
- 함수 원형: void swap(int *x, int *y)

정답 :
#include <stdio.h>

// 두 변수의 값을 바꾸는 함수 (포인터 매개변수 사용)
void swap(int* x, int* y) {
    int temp = *x; // x가 가리키는 곳의 값을 임시 저장
    *x = *y;       // y가 가리키는 곳의 값을 x가 가리키는 곳에 넣음
    *y = temp;     // 임시 저장해둔 값을 y가 가리키는 곳에 넣음
}

int main() {
    int a = 10, b = 20;
    printf("바뀌기 전 : a = %d, b = %d\n", a, b);
    swap(&a, &b);
    printf("바뀐 후 : a = %d, b = %d\n", a, b);
}
